## 🚀 Key Features

- **Real-Time CRUD:** Add and delete expenses with instant balance and total updates.
- **Smart Filtering:** Filter transactions by year and category to analyze spending patterns.
- **Persistent Storage:** Integrated with **LocalStorage** to ensure data persists after page refreshes.
- **Dynamic Feedback:** Real-time calculation of expenses versus budget.

## 🛠️ Technical Highlights

- **React Hooks:** Leveraged `useState` and `useEffect` for efficient state management and side effects.
- **Lifting State Up:** Managed complex data flow between the input forms and the display dashboard.
- **Responsive Design:** Engineered with a mobile-first approach using **CSS Flexbox** and **Media Queries**.

## 🧠 Key Learnings

This project focused on mastering **Form Handling** and **Data Validation** in React. I implemented logic to ensure data integrity (preventing empty or invalid entries) and optimized the filtering logic to maintain high performance with larger datasets.
